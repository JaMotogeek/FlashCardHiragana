Flash Card V Nihongo

A Japanese language learning application built with Next.js, TypeScript, React, and Tailwind CSS.

The project is currently focused on an interactive flashcard system for learning Japanese hiragana and their corresponding romaji. Cards can be flipped between Japanese characters and their romanized pronunciation and are presented using a randomized deck system.

Future development may include additional Japanese character sets, vocabulary, handwriting practice, pronunciation practice, scoring, and other interactive language-learning features.

Current Features
Hiragana-to-romaji flashcards
Interactive card flipping
Randomized flashcard deck
Cards are removed from the active deck after use to prevent immediate repetition
Automatic deck reshuffling
Responsive web-based interface
